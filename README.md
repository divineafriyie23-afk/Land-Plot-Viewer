# Land Plot Viewer

An interactive web mapping application for visualizing land plots from geographic coordinates.

## Features

- Plot geographic coordinates on an interactive map
- Calculate plot perimeter and area
- Display area in square meters and acres
- Support for satellite, street, and hybrid map views
- Interactive visualization of land boundaries

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap

## About the Project

This project combines frontend web development with my background in Geomatic Engineering.

It was built to explore how web technologies can be used to visualize and work with real-world geographic data and land parcels.

## What I Learned

- Building interactive web interfaces with JavaScript
- Working with geographic coordinates
- Integrating interactive maps with Leaflet.js
- Performing spatial calculations for area and perimeter
- Connecting geomatics concepts with web development
